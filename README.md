# موقع شركة المهندس للصيانة و المقاولات العامة

موقع متكامل (Full-Stack): واجهة عامة للزوار + لوحة تحكم (Admin) لإضافة وتعديل وحذف
المشاريع وصورها بدون كتابة أي كود.

## هيكل المشروع

```
server.js              نقطة تشغيل الخادم (Express)
server/
  config/sectors.js     القطاعات الأربعة الثابتة (المقاولات العامة، التيار الخفيف، الإلكتروميكانيك، التبريد و التكييف)
  config/db.js           الاتصال بقاعدة بيانات MongoDB
  models/Project.js      نموذج بيانات المشروع
  routes/auth.js          تسجيل دخول الأدمن
  routes/projects.js      عرض/إضافة/تعديل/حذف المشاريع
  middleware/auth.js      حماية مسارات لوحة التحكم بتوكن JWT
  utils/imageStorage.js   رفع صور المشاريع (Cloudinary أو تخزين محلي كخيار احتياطي)
public/
  index.html              الموقع العام
  admin/index.html         لوحة التحكم (/admin)
  css/, js/, images/       التنسيقات والسكربتات والشعار
scripts/hashPassword.js   أداة لتوليد كلمة مرور مشفّرة لحساب الأدمن
.env.example              نموذج متغيرات البيئة المطلوبة
```

## 1) التجهيز قبل التشغيل

### أ) قاعدة البيانات - MongoDB Atlas (مجاني)
1. أنشئ حساباً على https://www.mongodb.com/cloud/atlas
2. أنشئ Cluster مجاني (M0)
3. من Database Access أنشئ مستخدم قاعدة بيانات بكلمة مرور
4. من Network Access اسمح بالوصول من أي مكان (0.0.0.0/0) حتى تعمل الاستضافة
5. من Connect احصل على رابط الاتصال (connection string) وضعه في `MONGODB_URI`

### ب) الصور - Cloudinary (اختياري لكن موصى به عند النشر الفعلي)
1. أنشئ حساباً مجانياً على https://cloudinary.com
2. من الـ Dashboard خذ: Cloud Name, API Key, API Secret
3. ضعهم في `CLOUDINARY_CLOUD_NAME` / `CLOUDINARY_API_KEY` / `CLOUDINARY_API_SECRET`
4. إذا تركتهم فارغين، الصور تُحفظ محلياً في `public/uploads` (مناسب للتجربة المحلية فقط،
   لأن أغلب الاستضافات المجانية تمسح الملفات المحلية عند إعادة التشغيل)

### ج) بيانات دخول لوحة التحكم
1. اختر اسم مستخدم وضعه في `ADMIN_USERNAME`
2. ولّد كلمة مرور مشفّرة:
   ```
   npm run hash-password -- "كلمة_المرور_التي_تريدها"
   ```
3. انسخ الناتج إلى `ADMIN_PASSWORD_HASH`

### د) انسخ `.env.example` إلى `.env` واملأ كل القيم، ثم ولّد `JWT_SECRET` عشوائي طويل.

## 2) التشغيل محلياً

```
npm install
npm start
```

- الموقع العام: http://localhost:5000
- لوحة التحكم: http://localhost:5000/admin

## 3) كيفية إدارة المشاريع

من `/admin`، سجّل الدخول ثم:
- **إضافة مشروع**: اختر القطاع، اكتب الاسم والوصف، ارفق صورة ورابط (اختياريان)، اضغط حفظ.
- **تعديل مشروع**: اضغط "تعديل" على أي بطاقة، عدّل البيانات، اضغط حفظ.
- **حذف مشروع**: اضغط "حذف" وأكّد.

المشروع الذي لا تُضاف له صورة يظهر في الموقع العام بعلامة "الصورة قيد الإضافة"،
والذي بلا رابط يظهر بعلامة "الرابط قيد الإضافة قريباً" - تلقائياً بدون أي تعديل يدوي.

## 4) النشر على استضافة حقيقية (Render مثالاً - مجاني)

1. اربط المستودع (repo) بحساب Render: https://render.com
2. أنشئ **Web Service** جديد من هذا المستودع
3. Build Command: `npm install`
4. Start Command: `npm start`
5. أضف كل متغيرات `.env` كـ Environment Variables في إعدادات الخدمة على Render
   (لا ترفع ملف `.env` نفسه إلى GitHub أبداً - هو مستثنى بالفعل عبر `.gitignore`)
6. بعد النشر، اربط الدومين الخاص بك (بعد شرائه) من إعدادات Render > Custom Domain

## ملاحظات أمان

- لا تشارك `JWT_SECRET` أو `ADMIN_PASSWORD_HASH` أو مفاتيح Cloudinary/MongoDB مع أي أحد.
- غيّر `JWT_SECRET` وكلمة مرور الأدمن قبل النشر الفعلي إذا كنت جربتهم محلياً بقيم بسيطة.
